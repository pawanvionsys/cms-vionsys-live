# cms-vionsys-live

Vionsys CMS — publishing platform for blogs and case studies on [vionsys.com](https://www.vionsys.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md) for required environment variables.

## Deploy

Configured for AWS Amplify. Set env vars in Amplify before deploying (database, JWT, S3, revalidation webhook).
